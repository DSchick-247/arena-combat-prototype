# Arena Combat Prototype

Wave-based melee combat prototype built in Unity using C#.

## Project Focus
This prototype was designed to demonstrate gameplay systems development, combat feedback implementation, enemy AI behavior, and iterative debugging workflows.

## Features
- Player movement and dodge system
- Melee combat system
- Enemy AI chase and attack behavior
- Multiple enemy archetypes
- Wave spawning system
- Combat feedback:
  - Knockback
  - Hit flash
  - Camera shake
- Win/Lose game states
- UI tracking:
  - Player health
  - Current wave
  - Enemies remaining

## Tools Used
- Unity
- C#
- Visual Studio
- TextMeshPro
- GitHub

## QA / Debugging Focus
This project emphasized iterative testing and debugging including:
- Prefab troubleshooting
- UI reference fixes
- Combat balancing
- Wave progression debugging
- State management fixes

## Project Goal
The goal of this project was to create a focused and functional gameplay prototype while demonstrating gameplay scripting, debugging, and QA-oriented workflows.
